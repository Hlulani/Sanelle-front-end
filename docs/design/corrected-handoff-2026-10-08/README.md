# Sanelle product-design handoff

This package is the exportable design specification for the current Sanelle prototype.

## Start here

1. Open `SANELLE_COMPLETE_SCREEN_ATLAS.html` for the exhaustive visual atlas.
2. Use `SANELLE_COMPLETE_SCREEN_ATLAS.pdf` for one-screen-or-state-per-page review.
3. Use `complete-screen-atlas-png/` for 111 individually named artboards plus an index.
4. Read `SANELLE_COMPLETE_JOURNEY_MAP.md` for all screen IDs and state transitions.
5. Import `SANELLE_COMPLETE_SCREEN_INVENTORY.csv` into a spreadsheet, tracker, or planning tool.
6. Open `SANELLE_HANDOFF.html` for the shorter product overview.
7. Read `SANELLE_USER_JOURNEYS.md` for detailed product and evidence rules.
8. Use `SANELLE_ASSET_MANIFEST.csv` to trace every supplied photo and vector.
9. Use `design-tokens.json` for colour, typography, spacing, and semantic-state references.

The earlier `SANELLE_SCREEN_ATLAS` files contain the 37 core flow screens. The `SANELLE_COMPLETE_SCREEN_ATLAS` files supersede them for exhaustive development review and include validation, loading, empty, unfinished, saved, compatibility, and status variants.

## Export

The HTML handoff is designed for browser printing:

- Open `SANELLE_HANDOFF.html`.
- Choose **Print**.
- Select **Save as PDF**.
- Enable background graphics.
- Use landscape orientation for the journey maps.

The Mermaid diagrams in `SANELLE_USER_JOURNEYS.md` can also be imported into Mermaid Live, Notion, GitHub, or compatible documentation tools.

## Package boundaries

- This is a design and product-behaviour handoff, not production authentication, OCR, medical interpretation, or clinical-validation code.
- Report extraction must preserve original wording, source, date, unit, and confirmation type.
- Missing data remains unknown.
- Draft, in-review, and withdrawn evidence entries remain outside patient-facing explanations.
- User health records and research participation require separate consent and data controls.

## Asset licence notes

Photography is downloaded from Unsplash for design-development use. Keep the photographer attribution in product credits or project documentation and verify the current Unsplash licence before production redistribution.
